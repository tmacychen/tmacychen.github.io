# 痛点与机遇
## 聊天工具的背后——社交网络
Robrix+ Palop 是聊天客户端+聊天服务器。其特点是利用Matrix 去中心化的分布式通信协议，提供端到端的加密通信，保证沟通双方隐私与通信安全。而专业的保密通信有专用保密信道，并非我们接触的通用互联网络。我们对于 Matrix 协议感兴趣的地方数据安全与隐私安全，但这都离不开聊天工具的核心价值是分享与传递信息。营销为主的企业用户十有八九都离不开企业微信，因为用户在微信社交网络中。钉钉，飞书等等一系列社交软件即使功能更完美，但也只能限定在企业内部使用。只要与客户建立关系，目前没有工具可以取代腾讯系的社交网络。微信当初也是踩着 QQ 拓宽了移动互联网的社交圈。聊天只是行为，工具带来最重要的价值是社交圈，是信息交换，是满足个人的分享欲与虚荣心。国内如此，而国外的情况更多样，例如有Facebook、WhatsApp 等,但每个 app 背后都有一套社交网络的壁垒。

## 从社区入手
如果想为聊天工具寻找应用场景，我们需要寻找/创建一个社区。虽然我们无法挑战微信/Facebook/WhatsApp 的社交网络，但我们可以从中挖出一块，让他们基于同类型的兴趣/目标/动机来到我们的圈子，使用我们的聊天工具，从而成为真正的种子用户。通过种子用户来推动聊天工具的进化，让更多的人加入我们的圈子，让我们的社交网络重新覆盖（而不是取代）旧时代的社交网络。



那创建一个怎样的社区，使用我们的聊天工具的同时，有隐私安全与加密通信的需求的同时，我们还能获得不错的收入？答案就是：一个为创业者/创业团队/创新产品定制的分享平台。

我暂时称其为 Startup 社区。在训练营过程中，我发现很多学员来自不同的专业背景，并非所有人都懂 github 的社交规则，并非所有人都会对代码感兴趣。那些创业项目的前期用户很可能还不会为提bug/issue。我们如何与种子用户交流？每个项目组都会搭建自己的社区论坛，组建自己的微信/飞书群聊，通过pages 建立项目首页，更新 blog 来同步项目进展。我们可以为创业团队提供一个信息发布平台，可以让创业团队公布项目目标，展示项目特点，同步项目进度，最重要的是，直接关联一个聊天节点，让用户可以直接接入社群聊天，面对面的反馈问题，面对面的沟通产品特性。一切都是新的起点，创业项目/种子用户/聊天社群。

+ 一个信息发布的平台
+ 一个为创业项目/开源软件/创新工具的展示平台
+ 一个创业者与用户面对面沟通的平台
+ 一个让投资者直接观察项目团队的平台

# 解决思路
## 信息发布与聊天社群的深度绑定
首先，startup 社区可以为创业项目提供一个信息发布板块，包括项目名称，项目特色，项目进展，问题留言版等功能。在发布板块右滑后，可以直接进入项目群聊组。初次加入项目群聊，默认进入用户群组。用户群组可以直接与项目的运营/产品/开发直接互动，交流用户最关心的问题。如果用户深度参入项目的测试/问题反馈/开发等活动，项目团队可以给用户提供认证勋章。同时可以邀请用户加入项目的测试群组/创意群组/核心用户群组/投资意向群组等。
![](/blog/decentralized-social/1.png)


## 创建稳固的社交网络
创业团队可以通过startup 社区获得稳定可靠的种子用户，初期开发者，潜在投资者。每个startup 社区用户在 startup 可以通过参与社区活动获得认证勋章，通过不同的勋章评价体系，得到能力认可/价值评价/技能标签等认证。其他的创业团队通过认证勋章体系即可获得对用户准确评价。
![](/blog/decentralized-social/2.png)



## 商业信息安全
基于分布式的加密通信体系，创业者可以搭建自己的聊天服务器，与种子用户，核心开发者，潜在投资者的所有沟通都可以留存在本地。关键核心交流可以采用端到端加密聊天，支持阅后即焚，身份认证等功能，确保商业机密的安全。

## 面对面竞争与获客
经常逛市场的会发现，卖菜的摊位会在一起，卖肉的摊位会在一起。商业区往往会有家装一条街，家具一条街，手机一条街，相同生意的店铺往往都会扎堆。相互直接竞争的店家为什么会选择扎堆，面对面竞争岂不是更加激烈？其实相比分散开店，扎堆会明显降低获客成本。同样的道理，我们将类似的创业项目在相同板块展示，更加容易让目标用户发现，并体验使用。对于潜在的投资者，也更容易通过不同项目对比发现亮点与优势。startup 社区就是一个项目的大市集，良性竞争才能促使诞生更优秀的产品，优质的创业项目。

# 商业机会
startup 社区的商业价值

- 广告收益

通过帮助创业团队获得用户，打造为创业圈的头部媒体，利用广告获益

- 增值服务

为创业团队提供基础设施服务（信息看板，项目首页，聊天服务，需求匹配）的基础上，提供带有附加值的增值服务（项目孵化指导，团队协作工具，项目管理工具，融资推广等）

- 社区裂变

通过不同的创业项目，吸引不同社区的用户与开发者进入 startup 社区，通过社区的即时聊天工具来形成圈子，在圈子里形成对 startup 社区的认可与信任，从而向外部扩展，为新的商机带来可能性

# 潜在市场

+ 构建产品原型，搭建基础社区框架
+ 种子用户使用与测试，反馈改进
+ 宣发稳定预览版，从传统社群中吸引用户，扩大用户范围
+ 利用头部创业项目，吸引高质量用户与媒体，从而扩大 startup 社区影响力
+ 为创业团队打造协作工具，更好的吸引新的创业项目入住，提供增值服务
+ 从创业社区扩展为圈子社交平台
